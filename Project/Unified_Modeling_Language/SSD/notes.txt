UML (Unified Modeling Language)

UML is a visual language used to design and describe software systems.

It helps developers show:

        system structure
        
        system behavior
        
        interactions between components
        
        UML uses diagrams to represent systems.

SSD (System Sequence Diagram)
    An SSD is a type of sequence diagram used in system analysis.
It shows:

        interaction between actor and system
        
        messages sent to the system
        
        order of operations
